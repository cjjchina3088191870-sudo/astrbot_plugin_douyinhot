# 🔥 抖音热搜插件

获取抖音实时热搜榜并生成精美的报告输出。

## 功能特点

- ✨ 实时获取抖音热搜榜数据
- 📝 支持自定义返回数量
- 🎯 支持多种命令触发方式
- 🔢 自动格式化热度值（万、亿）

## 使用方法

### 命令触发
- `/douyinhot` - 获取前10条热搜
- `/douyinhot 20` - 获取前20条热搜

### 自然语言触发
- "抖音热搜"
- "抖音热点"
- "dyhot"
- "抖音"

## 配置说明

- 默认返回数量：10条
- 最大返回数量：50条
- API 地址：https://v2.xxapi.cn/api/douyinhot

## 输出示例

```
🔥 抖音热搜榜
1. 🔥 🎵 春节高速免费时段今晚结束
   🔥 热度：1215.6万
2. 🔥 🎬 新春里的一百个"想不到"
   🔥 热度：1190.9万
3. 🔥 🌟 好像每个车里都塞满了妈妈的爱
   🔥 热度：1165.4万

🕐 时间：2025-02-23 18:00:00
📊 数据来源：抖音
```

## 注意事项

1. API 请求可能会失败，插件会自动返回友好的错误提示
2. 热度值会自动格式化（如：1000万、1.5亿等）
3. 前三名会有特殊标记 🔥
